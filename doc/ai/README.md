# Registros de trabalho

Esta pasta guarda o contexto necessário para retomar o desenvolvimento. Os guias
de uso e de código ficam no [índice da documentação](../README.md).

| Arquivo | Conteúdo |
| --- | --- |
| [progress.md](progress.md) | Tarefa atual, trabalho concluído, verificações, pausas e próximo passo. |
| [previous-plan-lessons.md](previous-plan-lessons.md) | Resumo das nove etapas do plano abandonado, evidências e cuidados reutilizáveis. |
| [history-before-p2p.md](history-before-p2p.md) | Registro integral anterior à redefinição P2P, sem autorização de retomada. |
| [decisions.md](decisions.md) | Decisões tomadas, motivos e pontos ainda em discussão. |
| [requirements.md](requirements.md) | Cópia exata do pedido original, preservada para consulta. |
| [verification-history.md](verification-history.md) | Preparação do ambiente, consultas de versões e resultados anteriores retirados dos guias. |
| [http-notes.md](http-notes.md) | Detalhes provisórios e notas de implementação retirados dos guias de rotas e erros. |
| [security-filesystem-notes.md](security-filesystem-notes.md) | Notas de segurança e arquivos, com as verificações que ainda faltam. |

Progresso, decisões e pedido original foram movidos de `doc/` para esta pasta. O pedido original
mantém o texto recebido, inclusive as referências aos caminhos antigos. Para o
trabalho atual, use os caminhos de [AGENTS.md](../../AGENTS.md).

O plano antigo foi abandonado. As diretrizes P2P posteriores substituem suas
premissas incompatíveis; um novo plano de código depende de solicitação do usuário
depois da documentação. Os registros históricos não devem ser executados.

Relatos de execução e notas para a IA pertencem a esta pasta. A documentação
pública deve explicar como o projeto funciona e como usá-lo.
